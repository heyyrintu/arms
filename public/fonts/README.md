# Self-hosted ARMS typefaces

- `Montserrat-*.subset.woff`: supplied by the owner’s 17 November 2026 design system (`design-system/assets/fonts/`). Five provided faces are copied unchanged by `npm run design:sync`. Licence: `Montserrat-OFL.txt` (SIL Open Font License 1.1).
- `NotoSansDevanagari.ttf`: official Google Fonts variable font, downloaded 17 November 2026 from [google/fonts](https://github.com/google/fonts/tree/main/ofl/notosansdevanagari). Original filename: `NotoSansDevanagari[wdth,wght].ttf`. Unmodified; licence: `NotoSansDevanagari-OFL.txt` (SIL Open Font License 1.1).

Fonts are served by this website; visitor requests never go to Google Fonts. Noto supplies Hindi glyphs alongside Montserrat’s Latin text. The Hindi face is preloaded for Hindi pages. Font files and licence text must travel together in deployments.
